### 🔀 Como trabalhamos

```text
ideia → protótipo → branch → revisão → merge
```

1. **Ideia:** que problema vale resolver, e para quem.
2. **Protótipo:** uma versão rápida para ver se a ideia para em pé.
3. **Branch:** cada um puxa a sua parte num branch próprio, sem pisar no pé do outro.
4. **Revisão:** nenhuma linha entra na `main` sem o outro ler. É aqui que mais aprendemos.
5. **Merge:** as partes se juntam, como os dois sobrenomes no nome.
